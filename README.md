# ♻️ _Webpage_ didática com Bootstrap
Uma _webpage_ feita para fins avaliativos na disciplina de **Programação Front-End**, ministrada pelo professor Lucas José de Souza (@[lucas231090](https://github.com/lucas231090/)).

Foi desenvolvida com foco no tema de sustentabilidade, seu impacto na saúde no planeta e os níveis de responsabilidade que tanto pessoas como grandes empresas precisam ter para evitar esgotamento de recursos e catástrofes ambientais.

> **Nota**: o projeto estava sendo desenvolvido utilizando ``npm`` para criar um projeto utilizando Bootstrap de forma *offline*. Porém, como a página precisava ser hospedada pelo Github Pages, este projeto foi adaptado para utilizar o CDN fornecido pelo Bootstrap remotamente. Foi importado a folha de estilos ``styles.css`` inteira que havia sido gerada durante os testes para refletir a aparência que estive configurando à página. Planejo refinar este detalhe futuramente.

## Descrição da Atividade
**Requisitos mínimos**
- Usar HTML + CSS (Bootstrap);
- Implementar ao menos 3 componentes do Bootstrap (ex: navbar, cards,
carousel, form etc.);
- Página responsiva (pode ser usando as classes do grid do Bootstrap);
- Deve possuir um formulário de cadastro (livre)
- Publicar no GitHub Pages;
- Incluir um `README.md` explicando o projeto.

**Temas possíveis**
1. **Agenda 2030**

    1. ➡️ **Site sobre Sustentabilidade no Dia a Dia**: Explicando como pequenas ações (reciclagem, economia de água, consumo consciente) ajudam o planeta.
    Pode incluir dicas, infográficos, etc.
    2. **Site sobre os 17 Objetivos de Desenvolvimento Sustentável (ODS)**: Uma página para cada ODS com explicações, metas e exemplos.
    3. **Desigualdade Social no Brasil**: Site com dados, gráficos simples (com JS ou imagem), explicações e propostas.
    4. **Consumo Responsável e Moda Sustentável**: Landing page de uma marca de roupas sustentável fictícia com conteúdo sobre o impacto da moda no meio ambiente.

2. **Temas indigenistas**

    1. **Cultura e Saberes dos Povos Indígenas**: Site educativo sobre tradições, línguas, arte, e saberes indígenas. Pode incluir seções com
    vídeos, imagens e curiosidades.
    2. **Terras Indígenas e Meio Ambiente**: Foco na importância das terras indígenas para a preservação de florestas e biodiversidade.
    3. **Línguas Indígenas Brasileiras**: Site com um pequeno glossário, áudios ou textos sobre línguas ameaçadas de extinção.
    4. **Direitos dos Povos Indígenas no Brasil**: Site explicando direitos garantidos na Constituição, lutas recentes, marcos legais (ex: PL do Marco Temporal).
    5. **História e Resistência Indígena**: Linha do tempo com momentos importantes da história indígena no Brasil, de 1500 até hoje.
